  Keyboard is live. The 4×14 layout is generated from M5Cardputer's own
  _key_value_map, so it cannot drift from the hardware. Clicking a key sends its
  matrix coordinate — the firmware decodes it through the same table a physical
  press uses. Hover a key to see its row/column.

  Every cap shows both legends. The small dim symbol above each key is the
  shifted character — click it directly to send that symbol; no need to latch
  shift first. All 56 keys and 107 legends are reachable, and the
  layout scales to fit all 14 columns at any panel width.

  Arrows: the ADV has four dedicated arrow keys — an inverted-T,
  marked ↑ ← ↓
  → above. No fn is needed: press them directly,
  or use Capture my keyboard and press real arrow keys.
  They report as ; , . / because
  M5Cardputer reuses the original Cardputer's value map — the keycap legend and the
  reported character differ, which is a library detail, not a missing key.

  If colors look wrong, try Swap R/B or Invert: the panel is
  read back as RGB888 and byte order varies between ST7789 revisions. A self-test
  well under 100% means 3-wire GRAM readback is unreliable on this unit — see ADR 0001.
